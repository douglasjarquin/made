=== LIMITATION NOTE ===
The gh token available in this environment has scopes 'gist, project, read:org,
repo, workflow' but NOT 'delete_repo'. gh repo delete on the scratch repo created
for this test fails with:
  HTTP 403: Must have admin rights to Repository.
  This API operation needs the "delete_repo" scope.
The scratch repo (douglasjarquin/made-task16-scratch-test-1786607476, private)
and the open PR above are therefore left in place - not automated test fixtures,
a one-time manual scratch repo created for this task's live verification. Doug
should delete the repo manually, or run:
  gh auth refresh -h github.com -s delete_repo
and then:
  gh repo delete douglasjarquin/made-task16-scratch-test-1786607476 --yes
No further scratch repos were created in order to avoid compounding this cleanup
debt. All other tests in this package use a compiled fake `gh` CLI double
(internal/github/testdata/fakegh) with zero network/account side effects, and
the live test (internal/github/live_test.go) is skipped by default in `go test
./...` unless MADE_GITHUB_LIVE_TEST_REPO is explicitly set, so it never runs
unattended in CI or on a fresh clone.
