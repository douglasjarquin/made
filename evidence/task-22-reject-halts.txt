Task 22 evidence: made review - reject halts
==================================================

LIMITATION (read this first): StatusReport.PendingFindings is always an
empty slice from a real `made daemon` today, because no orchestrator yet
drives a submitted run through the Review/Document stages that produce
ask-user findings (Task 21's honest documentation of this gap still holds;
see cmd/made/status.go's StatusReport doc comment). This QA run therefore
uses a tiny throwaway harness (tools/qaharness/main.go, deleted after this
evidence was captured, not part of the delivered diff) that serves the real
internal/api.Server and the exact same "status" / "review.decide" /
"review.decision" wire contract cmd/made/review.go implements, with a fixed
PendingFindings fixture standing in for a real pipeline run. The `made`
binary under test below is the real, unmodified, compiled cmd/made binary -
only the daemon side of the "status" call is faked, for the reason above.
